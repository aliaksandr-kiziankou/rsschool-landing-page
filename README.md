# Team Styrit — Esports Organization

Responsive two-page website for **Team Styrit**, a fictional professional esports organization.

The project was created as part of the **RS School JavaScript/Frontend course** using an original esports design instead of the provided Coffee House concept.

## Pages

* `index.html` — hero, featured matches, teams, achievements.
* `roster.html` — team categories and player roster.

## Technologies

* HTML5
* CSS3
* JavaScript
* CSS Grid / Flexbox
* CSS Custom Properties
* `localStorage`

No frameworks, libraries, TypeScript, Vite or CSS frameworks are used.

## Features

* Responsive design: 1440px → 380px
* Dark / light themes
* Theme persistence with `localStorage`
* Responsive mobile layout
* Semantic HTML5
* Smooth scrolling
* Hover effects and transitions
* Accessible image `alt` attributes
* Favicon
* Internal and external navigation
* 3 esports team categories
* 8 player cards
* Featured matches slider layout
* Load More button

## Design

The visual style combines a dark graphite interface, lime accent color, large typography, thin borders and a technical esports aesthetic.

Fonts: **Inter** and **Space Grotesk**.
